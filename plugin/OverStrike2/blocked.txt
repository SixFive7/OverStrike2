// The game-changers no map may set, in every game mode. A map that sets one of these gets it put back within a second - right after its
// own cfgs and entities have run, and again whenever it tries later - and every block is logged. A player's choice on the menu's fun page
// is never blocked. The movement settings bhop and surf maps need (sv_airaccelerate, bunny hopping, stamina, sv_gravity, fall damage) are
// deliberately NOT here; the bridge's --selftest fails if one is added.
//
// Format (bridge/Modes.cs, Modes.Blocked): one convar per line, then the value it keeps in each mode - Arms Race, Deathmatch, Wingman, in
// that order - then // and why. * keeps the server's own value (its baseline, taken when the boot map ends, an Arms Race map), so only Arms
// Race uses it. Deathmatch's values are Valve's gamemode_deathmatch.cfg plus server/gamemode_deathmatch_server.cfg, Wingman's Valve's
// gamemode_competitive2v2.cfg plus server/gamemode_competitive2v2_server.cfg. Counts are Workshop items setting it in the 2026-10-22 scan of
// all ~3,600 cached items. Deploy beside OverStrike2.dll; the plugin reads it at load, at the first map start in another mode, and on
// "mapreset_block reload".
//
// convar                          armsrace  deathmatch  wingman   // why

// ---- the mode and cheats ----
game_type                          1         1           0         // the game mode (Arms Race 1/0, Deathmatch 1/2, Wingman 0/2): 29 items switch it, which would carry into the next map
game_mode                          0         2           2         // the same, 28 items
sv_cheats                          *         0           0         // 93 items turn cheats on, which lets every player use cheat commands for the rest of the map

sv_infinite_ammo                   *         2           0         // Arms Race and Deathmatch run 2 (endless reserve, reloads as usual), Wingman 0 (ammo runs out); 28 items set 1 (no reloads) or 0 (run dry)

// ---- damage and who is an enemy ----
mp_damage_headshot_only            *         0           0         // headshots only: 2 items

sv_hegrenade_radius_multiplier     *         1           1         // grenade blast radius: 2 items

mp_respawn_on_death_ct             *         1           0         // 28 items; 0 stops CTs respawning - in Wingman's rounds the dead wait for the next round
mp_respawn_on_death_t              *         1           0         // 26 items; 0 stops Ts respawning - the same
mp_timelimit                       *         2           0         // 15 items; a time limit ends the map in the middle of a match (Deathmatch keeps Valve's 2; Wingman's rounds end its match)
mp_match_end_restart               *         1           1         // 5 items; the server replays the map after a match, and the bridge's vote picks the next one
mp_match_end_changelevel           *         0           0         // 1 item; a changelevel at the match end would go past the bridge's vote
mp_warmup_pausetimer               *         0           0         // 7 items set 1: warmup never ends, so the match never starts
sv_allow_votes                     *         0           0         // 4 items turn the F1/F2 votes on (kick, change level), which the server switched off: the bridge's vote is the vote
bot_quota                          *         0           0         // 37 items add bots, and Valve's Deathmatch and Wingman add their own; this server runs none (CounterStrikeSharp #1446)
bot_quota_mode                     *         normal      normal    // fill_with_minimum adds a bot even at bot_quota 0 (seen live in Deathmatch); Arms Race's own is fill

mp_weapons_allow_map_placed        *         0           1         // 19 items: guns lying on the map can be picked up - in Wingman, as Valve has it

mp_death_drop_grenade              *         0           3         // 2 items set 0 in Arms Race, which would stop the grenade drops; Deathmatch drops nothing, Wingman the grenades too
